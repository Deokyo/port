01 / Contexto

Desafio

O arquivo explora uma possível experiência de evento sem briefing final de data, local ou integração.

Objetivo da LP

Demonstrar como um tema técnico pode ser organizado em uma jornada clara de entendimento, identificação e estruturação.

02 / Atuação

Contribuição técnica

  • Conceito de jornada e composição visual
  • Protótipo frontend responsivo
  • Tratamento explícito de dados ainda pendentes
  • Estrutura noindex para não competir com páginas reais

03 / Experiência

Decisões de UI/UX

  • Visual de conformidade com scan e pontos de atenção
  • Fluxo em três etapas
  • Seção de público e inscrição demonstrativa
  • Hero técnico dentro do sistema de marca

04 / Código

Pontos técnicos

  • HTML, CSS e JavaScript vanilla
  • IntersectionObserver para reveal
  • robots noindex,nofollow
  • Nenhum formulário ou endpoint real
