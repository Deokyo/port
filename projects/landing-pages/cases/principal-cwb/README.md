## Contexto e desafio

A página precisava funcionar como ponto de entrada sem competir com as LPs específicas de cada serviço.

## Objetivo da LP

Apresentar o portfólio de soluções, ajudar na identificação da necessidade e encaminhar para a página ou contato adequado.

## Minha contribuição técnica

- Arquitetura do hub e interligação entre páginas
- Implementação editorial em HTML, CSS e JavaScript
- SEO e navegação por links reais
- Integração do formulário de orientação

## Principais decisões de UI/UX

- Hero com núcleo Locatelli e categorias orbitais
- Mapa de soluções como elemento de orientação
- Seção laranja para ruptura e decisão
- Header reduzido com uma ação principal

## Pontos técnicos

- Links cruzados para LPs específicas
- Layout adaptativo para o mapa de soluções
- Motion progressivo e reduced-motion
- Form shell isolado para RD Station
